# Проект: демо-сайт автосервиса «Богема Механикс»

Второй демо-кейс портфолио (первый — сайт салона «Мастерская по созданию красоты»,
https://romankolesnikov1392-jpg.github.io/masterskaya-beauty-site/). Задача этого — выглядеть
объёмнее и дороже, с принципиально другим настроением: тёмная индустриальная тема, один янтарный акцент.

## Правила по контенту
- Не выдумывать цены, стаж, количество клиентов и другие факты. Источники: бриф заказчика и страница
  сервиса на Zoon. Если данных нет — `price: null` («по запросу») или блок скрыт.
- Расхождения брифа и Zoon (зафиксированы в комментариях `src/data/business.ts`): год основания
  2007 (бриф) vs 1996 (Zoon), рейтинг 5,0 (бриф) vs 4,9 (Zoon). Уточнить у владельца.
- Никаких «-50% сегодня»: тон — доверие и мастера, а не распродажа.

## Инструменты (использовать при любой работе с UI)
- shadcn/ui (стиль base-lyra) — база компонентов, перестилизована в `src/components/ui`.
- emilkowalski/skills: `emil-design-eng`, `animate`, `review-animations`, `improve-animations`.
- vercel-labs/agent-skills: `web-design-guidelines`, `vercel-react-best-practices`.
- Перед сдачей любой правки UI: ревью по web-design-guidelines и review-animations,
  затем скриншоты в браузере (десктоп 1440 и телефон 390) — не сдавать вслепую.

## Анимации (бриф)
200–400 мс, ease-out на входе, только transform/opacity, hover — за `(hover: hover)`,
всё под `prefers-reduced-motion`. Без мигающих и резких эффектов.

## Сборка
`npm run build` = tsc + vite build + SSR-сборка + пререндер в `dist/index.html`.
Компоненты должны рендериться одинаково на сервере и в браузере: время и даты — только в useEffect
(см. OpenStatus, Offers, `__BUILD_DATE__`).
